# BSE Events Hub

قم بعمل موقع جديد خاص أسمه BSE Event 
هذا الموقع عبارة عن قسم إدارة الفعاليات و المؤتمرات و المعارض لجمعية المهندسين البحرينينة وقم بإستخدام معلوماتهم من هنا bse.bh/ar 
يصب تركيز هذا الموقع على أن يكون موقع تعريفي بخدمات قسم الفعاليات و المؤتمرات و الأنشطة التي تقوم بها الجمعية و يستهدف عدة فئات من الزوار للموقع ( رعاة الفعاليات , الحضور للفعاليات , الشركات الرعاة و الشركات المنظمة للفاعليات ) و ينقسم الموقع إلى عدة صفحات :
1. الصفحة الرئيسية و التي تعرض هيروا بسلايدات + تعرض بطاقات لللفعاليات و باقي الصفحات مع نبذة عنا 
2. صفحة من نحن و أهدافنا تشرح الأهداف و كل شيء 
3. فريق العمل حيث يبين حجم الفريق 
3. صفحة المؤتمرات
4.صفحة المعارض ) في هذه الصفحة ستكون هناك المعارض الحالية و السابقة و ستكون في بداية الصفحة قسم خاص للنسخ المعارض الخاصة بالجمعية و كل معرض عند الضغط عليه ستظهر الخط الزمني لها و روابط صفحات الخاصة بكل نسخة )( لدينا المعرض الدولي للدراسات + معرض كروجن هذه معارض خاصة بجمعية المهندسين )
5.صفحة الفعاليات ( ستكون خاصة بفعاليات الجمعية  وستشمل فعاليات و أنشطة و ندوات الجميعة )
صمم الموقع بإحترافية كاملة وتصميم إحترافي و إستخدام للمكتبات بشكل صحيح + أجعله بللغتين و قم بالبحث عن كل الفعاليات و المعارض و المؤتمرات للجمعية المهندسين البحرينية و المعلومات المشابه وقم بإستعمالها لبناء الموقع
